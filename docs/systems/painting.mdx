# Custom Painting

Millager adds one custom painting: **"How to Make a Molotov Cocktail"**.

## Details

| Property | Value |
|----------|-------|
| Title | How to Make a Molotov Cocktail |
| Author | lzyzl6 |
| Size | 4×4 blocks |
| ID | `millager:how_to_make_a_molotov_cocktail` |

## Obtaining

The painting can be obtained in two ways:

- **Commander Trade** (level 2) — buy it with Emeralds
- **Creative Inventory** — available in the Millager creative tab

## Placement

The painting is tagged in `#millager:placeable`, making it valid for placement. It behaves like any vanilla painting — place it on a wall and it will display as a 4×4 artwork.

## Theme

The painting depicts the crafting recipe for a Molotov Cocktail, serving as an in-world tutorial for players who discover it.
