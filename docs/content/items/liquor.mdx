# Liquor

A strong alcoholic brew. Drinking it applies **Nausea** for 30 seconds. It is the essential base ingredient for brewing [Elixir](/content/items/elixir).

<PrefabObtaining />

## Brewing

Liquor is brewed in a [Liquor Cauldron](/content/blocks/liquor_cauldron) — **not** a vanilla Brewing Stand. See the [Brewing](/systems/brewing) guide for full details.

## Usage

- Drink to apply Nausea (30s) — mostly for the challenge
- **Essential ingredient** for brewing Elixir in a Brewing Cauldron
- Can be sold to Farmer villagers via the liquor trade

<Callout variant="warning">
Drinking Liquor applies Nausea. It is not recommended as a food source.
</Callout>
