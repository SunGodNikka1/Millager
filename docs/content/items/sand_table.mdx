# Sand Table

The job site block for the [Commander](/docs/systems/commander_trading) villager profession. A 3D micro-diorama table used for strategic planning.

<PrefabObtaining />

## Usage

- Place in a village to allow villagers to take the **Commander** profession
- Commander villagers use this block to restock trades
- The block is the **Command POI** (Point of Interest) for the Commander profession
- See the [Commander Trading](/docs/systems/commander_trading) guide for trade details
