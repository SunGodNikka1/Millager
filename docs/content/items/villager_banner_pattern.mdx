# Villager Banner Pattern

A banner pattern that applies the **Villager Head** motif to banners. Available in all 16 dye colors through banner crafting.

<PrefabObtaining />

## Usage

- Combine with a banner and dye in a Loom to apply the Villager Head pattern
- 16 color variants available (one per dye color)
- Found as rare loot in [Command Post](/docs/systems/command_post) chests
- Also dropped by [Rioter](/content/entities/rioter) Millagers (5% chance)
