# Spawn Eggs

Spawn Eggs for all Millager entities. Available in the Creative Mode inventory under the **Millager** tab.

| Spawn Egg | Entity | Description |
|-----------|--------|-------------|
| Archer Spawn Egg | [Archer](/content/entities/archer) | Ranged crossbow unit |
| Lancer Spawn Egg | [Lancer](/content/entities/lancer) | Mounted cavalry with healing aura |
| Swordmaster Spawn Egg | [Swordmaster](/content/entities/swordmaster) | Elite melee fighter with shield stance |
| Mauler Spawn Egg | [Mauler](/content/entities/mauler) | Durable tank with self-repair |
| Rioter Spawn Egg | [Rioter](/content/entities/rioter) | Shield-bearer with taunt and projectiles |
| Scouter Spawn Egg | [Scouter](/content/entities/scouter) | Cavalry scout with reinforcement horn |
| Doctor Spawn Egg | [Doctor](/content/entities/doctor) | Support unit that builds golems |
| Bee Golem Spawn Egg | [Bee Golem](/content/entities/bee_golem) | Glass-and-wax suicide drone |

<Callout variant="info">
Spawn Eggs are only available in Creative Mode. In Survival, Millagers spawn naturally through [Patrols](/docs/systems/patrols) and [Raid Defense](/docs/systems/raid_defense).
</Callout>
