# Molotov Cocktail

The projectile created when a [Molotov Cocktail](/content/items/molotov_cocktail) or [Molotov Cocktail +](/content/items/molotov_cocktail_plus) is thrown.

| Stat | Value |
|------|-------|
| Type | Throwable |
| Behavior | Spawns Enduring Fire |

## Behavior

- Follows a throwing arc
- On impact, spawns multiple [Enduring Fire](/content/blocks/timed_fire) blocks
- The Molotov Cocktail + variant creates a larger spread
- Does **not** deal direct impact damage — the fire does the work
