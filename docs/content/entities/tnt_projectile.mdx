# TNT Projectile

The projectile entity created when [TNT on a Stick](/content/items/tnt_on_a_stick) is thrown. Follows a trident-like throwing arc and explodes on impact.

| Stat | Value |
|------|-------|
| Type | Throwable |
| Behavior | Explodes on impact |

## Behavior

- Thrown using a trident-like charging and throwing animation
- Charge time determines throw distance and power
- Explodes on contact with a block or entity
- Explosion damages entities but **does not destroy blocks**
- The explosion counts kills for the **Carpet Bombing** and **Tactical Strike** advancements
