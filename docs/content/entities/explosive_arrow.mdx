# Explosive Arrow

The projectile entity fired when an [Explosive Arrow](/content/items/explosive_arrow) is shot from a bow.

| Stat | Value |
|------|-------|
| Type | Arrow |
| Behavior | Explodes on impact |

## Behavior

- Travels like a regular arrow
- Creates a small explosion on contact with a block or entity
- Explosion damages entities but **does not destroy blocks**
- Can be fired from any bow type
