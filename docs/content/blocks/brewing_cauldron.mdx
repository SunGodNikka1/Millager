# Brewing Cauldron

<PrefabObtaining />

A functional cauldron used in the second stage of the Millager brewing system. Combine [Liquor](/content/items/liquor) with rare ingredients to brew [Elixir](/content/items/elixir).

## Properties

| Property | Value |
|----------|-------|
| Hardness | 2.0 |
| Tool | Pickaxe |
| Full Block | No (cauldron shape) |
| Block Entity | Yes |

## Functionality

- Fill with Liquor (right-click with a Liquor bottle)
- Add rare ingredients to begin brewing
- Bottle the resulting Elixir
- The block entity tracks brewing progress over time
- See the [Brewing](/docs/systems/brewing) guide for the complete recipe

## Breaking

Broken with a Pickaxe. Drops itself.
