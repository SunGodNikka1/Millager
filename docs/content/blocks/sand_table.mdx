# Sand Table

<PrefabObtaining />

A 3D micro-diorama table. This is the job site block for the [Commander](/docs/systems/commander_trading) villager profession.

## Properties

| Property | Value |
|----------|-------|
| Hardness | 2.5 |
| Tool | Axe |
| Full Block | Yes |

## Functionality

- **Commander Job Site** — Unemployed villagers near this block can become Commanders
- The block serves as the **Command POI** (`millager:command_poi`)
- Commanders use it to restock their trades
- Has a unique 3D model with no occlusion

## Breaking

Broken with an Axe. Drops itself.
