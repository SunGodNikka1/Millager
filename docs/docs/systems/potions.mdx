# Potions

Millager adds the **Potion of Ascension** and its long variant. These potions provide a unique combination of mobility and stealth effects.

## Potion of Ascension

| Effect | Duration |
|--------|----------|
| Levitation | 0:20 |
| Slow Falling | 0:33 |
| Invisibility | 0:12.5 |
| Regeneration II | 0:10 |

## Potion of Long Ascension

| Effect | Duration |
|--------|----------|
| Levitation | 0:40 |
| Slow Falling | 1:06 |
| Invisibility | 0:22.5 |
| Regeneration II | 0:20 |

## Effect Breakdown

- **Levitation** — floats you upward; combined with Slow Falling for a safe descent
- **Slow Falling** — prevents fall damage, making Levitation safe to use
- **Invisibility** — hides you from most mobs during ascent
- **Regeneration II** — heals any damage taken

## Brewing

```
Awkward Potion + Torchflower → Potion of Ascension
Potion of Ascension + Redstone → Potion of Long Ascension
```

## Variants

Like all vanilla potions, Ascension comes in four forms:

- **Potion of Ascension** — drink to self-apply
- **Splash Potion of Ascension** — throw to apply to entities
- **Lingering Potion of Ascension** — throw to create a lingering cloud
- **Arrow of Ascension** — tipped arrow variant

All variants (including both normal and long) are available in the Millager creative tab.
