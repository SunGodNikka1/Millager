# Getting Started

Welcome to **Millager** — a mod that arms the villager side with a standing military, AI patrols, raid reinforcements, and a new brewing-based progression system.

## What Millager Adds

- **7 Millager combat units** — Archer, Lancer, Doctor, Swordmaster, Mauler, Rioter, Scouter — each with unique AI and roles
- **1 Construct** — Bee Golem, a self-guided kamikaze drone
- **Wild Patrols** — infantry squads and cavalry scouts spawn naturally after 3 in-game days
- **Raid Defense** — Millager reinforcements deploy in waves when a village is raided
- **Commander Profession** — a new villager with 5 trade levels, using the Sand Table as job site
- **Brewing System** — Liquor Cauldron → Brewing Cauldron → Elixir pipeline
- **Weapons** — TNT on a Stick, Molotov Cocktails, Explosive Arrows
- **Command Post** — worldgen structure with loot and explorer maps

## Recommended Progression

1. **Explore** — find a natural Command Post structure for early loot and explorer maps
2. **Meet a Commander** — place a Sand Table in a village to create a Commander villager
3. **Start Brewing** — craft a Liquor Cauldron, brew Liquor from crops, then brew Elixir with rare ingredients
4. **Trade** — level up your Commander to buy TNT on a Stick, Molotov Cocktails, Golem Amber, and Totems of Healing
5. **Fight** — use your arsenal to defend against raids and clear hostile mobs alongside Millager patrols

## Configuration

Two game rules control Millager spawning:
- `/gamerule millager:spawn_millager_patrols false` — disables wild patrols
- `/gamerule millager:raid_defenses false` — disables raid reinforcements

Both default to `true`.
