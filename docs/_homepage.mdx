# Millager

**Millager** adds a standing military to the villager side — infantry, cavalry, and constructs — with AI formation patrols, raid reinforcement waves, and garrisoned Command Posts.

## Key Systems

| System | Summary |
|--------|---------|
| [Commander Trading](/systems/commander_trading) | A new villager profession using the Sand Table as job site. 5 trade levels for weapons, intel maps, and healing totems. |
| [Brewing](/systems/brewing) | Liquor Cauldron → Brewing Cauldron → Elixir. A multi-stage brewing pipeline using crops, rare ingredients, and amethyst. |
| [Elixir Curing](/systems/elixir_interaction) | Cure NITWIT villagers with Elixir, transforming them into normal villagers. |
| [Raid Defense](/systems/raid_defense) | Millagers automatically reinforce your village during raids. Cavalry and infantry deploy in alternating waves. |
| [Patrols](/systems/patrols) | Wild Millager patrols spawn naturally after 3 in-game days. Infantry squads and cavalry scouts form formations. |
| [Command Post](/systems/command_post) | A worldgen structure found across forests, plains, and mountains. Lootable chests and explorer maps. |
| [Advancements](/systems/advancements) | 9 custom advancements across Husbandry and Adventure tabs. |
| [Game Rules](/systems/game_rules) | Toggle raid defenses and patrol spawning via `/gamerule`. |
