# 烈酒

一种烈性酒精饮料。饮用后施加**反胃**效果30秒，但它同时也是酿造[灵药](/content/items/elixir)所必需的基液。

<PrefabObtaining />

## 酿造

烈酒需要在[装有烈酒的炼药锅](/content/blocks/liquor_cauldron)中酿造——**不是**原版酿造台。详见[酿造系统](/systems/brewing)指南。

## 用途

- 饮用后获得反胃效果（30秒）——主要用于挑战
- **酿造灵药的必要原料**，需在酿造中的炼药锅中进一步加工
- 可卖给农民村民

<Callout variant="warning">
饮用烈酒会获得反胃效果。不建议作为食物来源。
</Callout>
