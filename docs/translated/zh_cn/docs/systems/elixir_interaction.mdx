# 灵药与傻子治愈

[灵药](/content/items/elixir)拥有两种强大功能：为玩家消除有害状态效果，以及**治愈傻子村民**使其变为正常村民。

## 治愈傻子村民

傻子村民（绿色衣着、无法就业的失业村民）可以用灵药**治愈**：

1. 找到一个傻子村民
2. 在主手中持有灵药
3. 右键点击傻子村民

傻子村民转化为**失业正常村民**，同时释放粒子和音效。村民会掉落25–36个绿宝石块作为奖励。

<Callout variant="info">
此互动解锁隐藏挑战进度**"世间难有聪明药"**。
</Callout>

## 傻子如何检测灵药

当持有灵药的玩家进入傻子8格范围内时：
- 傻子主手显示一个绿宝石块
- 它转头看向玩家
- 手持物品掉落概率为0%（无法利用刷物品）

## 消除负面效果

玩家饮用灵药时：
- **所有有害状态效果**被移除（中毒、凋零、失明等）
- **8种正面效果**施加30分钟（完整列表见[灵药](/content/items/elixir)页面）

这使得灵药在激烈战斗中是极佳的应急物品。

## 灵药配方

灵药在[酿造中的炼药锅](/content/blocks/brewing_cauldron)中由[烈酒](/content/items/liquor)和稀有原料酿造。完整流程见[酿造系统](/docs/docs/systems/brewing)指南。
