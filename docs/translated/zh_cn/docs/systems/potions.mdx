# 药水

Millager添加了**飞升药水**及其延长版。这些药水提供独特的机动与隐身效果组合。

## 飞升药水

| 效果 | 时长 |
|------|------|
| 飘浮 | 0:20 |
| 缓降 | 0:33 |
| 隐身 | 0:12.5 |
| 生命恢复 II | 0:10 |

## 延长版飞升药水

| 效果 | 时长 |
|------|------|
| 飘浮 | 0:40 |
| 缓降 | 1:06 |
| 隐身 | 0:22.5 |
| 生命恢复 II | 0:20 |

## 效果解析

- **飘浮**——使你向上浮起；配合缓降安全落地
- **缓降**——防止摔落伤害，使飘浮变得安全
- **隐身**——在上升过程中隐藏你
- **生命恢复 II**——治愈所受伤害

## 酿造配方

```
粗制的药水 + 火把花 → 飞升药水
飞升药水 + 红石粉 → 延长版飞升药水
```

## 变体

如同所有原版药水，飞升药水有四种形态：

- **飞升药水**——饮用以自身施加
- **喷溅型飞升药水**——投掷以对实体施加
- **滞留型飞升药水**——投掷以产生滞留药水云
- **飞升之箭**——药箭变体

所有变体（包括普通和延长版）均可在Millager创造标签页获取。
