# 入门指南

欢迎来到**戍村卫民（Millager）**——一个为村民阵营添加常备军队、AI巡逻、袭击增援和全新酿造进阶系统的模组。

## 模组添加内容

- **7种Millager战斗单位**——弓箭手、枪骑兵、博士、剑士、力士、暴徒、斥候——各具独特AI和定位
- **1种构装体**——蜂傀儡，自导神风无人机
- **野外巡逻队**——游戏时间3天后，步兵小队和骑兵斥候在野外自然生成
- **袭击增援**——村庄被袭击时，Millager援军分批部署
- **指挥官职业**——5级交易的全新村民，使用沙盘作为工作站点
- **酿造系统**——烈酒炼药锅→酿造炼药锅→灵药生产线
- **武器**——棍装TNT、莫洛托夫鸡尾酒、爆炸箭
- **指挥所**——带有战利品箱和探险家地图的世界生成结构

## 推荐发展路线

1. **探索**——找到自然生成的指挥所获取早期物资和探险家地图
2. **会见指挥官**——在村庄放置沙盘来产生指挥官村民
3. **开始酿造**——制作装有烈酒的炼药锅，用农作物酿造烈酒，再用稀有原料酿造灵药
4. **交易**——升级你的指挥官以购买棍装TNT、莫洛托夫鸡尾酒、傀儡琥珀和治愈图腾
5. **战斗**——使用你的武器库配合Millager巡逻队抵御袭击和清除敌对生物

## 配置

两个游戏规则控制Millager生成：
- `/gamerule millager:spawn_millager_patrols false`——禁用野外巡逻
- `/gamerule millager:raid_defenses false`——禁用袭击增援

两者默认均为`true`。
