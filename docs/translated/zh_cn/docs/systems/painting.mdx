# 自定义画作

Millager添加了一幅自定义画作：**"莫洛托夫鸡尾酒的制作工序"**。

## 详情

| 属性 | 值 |
|------|-----|
| 标题 | 莫洛托夫鸡尾酒的制作工序 |
| 作者 | lzyzl6 |
| 尺寸 | 4×4格 |
| ID | `millager:how_to_make_a_molotov_cocktail` |

## 获取方式

画作可通过两种途径获得：

- **指挥官交易**（2级）——用绿宝石购买
- **创造模式物品栏**——可在Millager创造标签页中获取

## 放置

画作已标记在`#millager:placeable`标签中，允许正常放置。它和原版画作行为一致——挂在墙上显示为4×4的绘画作品。

## 主题

画作描绘了莫洛托夫鸡尾酒的制作配方，为发现它的玩家提供了一个游戏内的制作教程。
