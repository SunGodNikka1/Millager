# 莫洛托夫鸡尾酒

一种投掷型燃烧武器。命中时产生[长明火](/content/blocks/timed_fire)——一种永不自然熄灭的特殊火焰。

<PrefabObtaining />

## 用途

- 投掷后在命中位置生成一片长明火
- 火焰持续燃烧，不会自然熄灭
- [暴徒](/content/entities/rioter)的主要远程攻击手段
- 投掷冷却1.0秒

<Callout variant="danger">
长明火不会被雨水或时间熄灭。需要用水或手动扑灭。
</Callout>
