# 傀儡琥珀

一块蕴含蜂傀儡精华的结晶。**右键使用**可召唤一只友好的[蜂傀儡](/content/entities/bee_golem)协助作战。

<Callout variant="info">
召唤出的蜂傀儡是临时构装体。承受足够伤害后会破碎。
</Callout>

<PrefabObtaining />

## 用途

- 右键使用在目标位置召唤一只蜂傀儡
- 可从[指挥官](/docs/systems/commander_trading)交易获取（5级）
- [博士](/content/entities/doctor)死亡时有概率掉落
