# 刷怪蛋

所有Millager实体的刷怪蛋。在创造模式物品栏的**戍村卫民**标签页下可获取。

| 刷怪蛋 | 实体 | 描述 |
|--------|------|------|
| 弓箭手刷怪蛋 | [弓箭手](/content/entities/archer) | 远程弩手单位 |
| 枪骑兵刷怪蛋 | [枪骑兵](/content/entities/lancer) | 拥有治愈光环的骑兵 |
| 剑士刷怪蛋 | [剑士](/content/entities/swordmaster) | 持盾姿态的精英近战 |
| 力士刷怪蛋 | [力士](/content/entities/mauler) | 可自我修复的肉盾坦克 |
| 暴徒刷怪蛋 | [暴徒](/content/entities/rioter) | 持盾嘲讽并投掷投射物 |
| 斥候刷怪蛋 | [斥候](/content/entities/scouter) | 吹响增援号角的骑兵斥候 |
| 博士刷怪蛋 | [博士](/content/entities/doctor) | 建造傀儡的后勤单位 |
| 蜂傀儡刷怪蛋 | [蜂傀儡](/content/entities/bee_golem) | 玻璃与蜡质神风无人机 |

<Callout variant="info">
刷怪蛋仅在创造模式可用。生存模式中，Millager通过[巡逻系统](/docs/systems/patrols)和[袭击增援](/docs/systems/raid_defense)自然生成。
</Callout>
