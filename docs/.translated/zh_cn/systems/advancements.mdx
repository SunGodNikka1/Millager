# 进度系统

Millager添加了**9个自定义进度**，分布于两个原版标签页：**农牧业**和**冒险**。多个进度使用了模组独有的自定义触发器类型。

## 农牧业标签页

| 进度 | 类型 | 触发 | 描述 |
|------|------|------|------|
| **小酌怡情** | task | `millager:obtain_liquor` | 酿造出一瓶烈酒 |
| **本地酿酒厂** | goal | `millager:brew_liquor` | 用小麦、马铃薯、甜菜根和小麦种子全部酿造 |
| **灵花妙药** | goal | `minecraft:consume_item` | 饮用灵药 |
| **世间难有聪明药** | challenge | `millager:heal_nitwit` | 用灵药治愈傻子村民 |

## 冒险标签页

| 进度 | 类型 | 触发 | 描述 |
|------|------|------|------|
| **狂轰滥炸** | task | `millager:tnt_kill` | 用棍装TNT炸死1只敌对生物 |
| **战术投弹** | challenge | `millager:tnt_kill`（最少6） | 用一根棍装TNT同时炸死6只以上敌对生物 |
| **军火贸易** | goal | `minecraft:villager_trade` | 和指挥官交易杀伤性道具 |
| **世纪大战** | challenge | `millager:grand_battle` | 在全部11波援军部署后赢得袭击 |
| **多核治疗** | goal | `millager:hold_totems` | 物品栏中持有2个以上治愈图腾 |
