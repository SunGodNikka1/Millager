# 指挥所

**指挥所**是一个作为Millager前哨站的世界生成结构。它有两种变体：完整的**指挥所**和废弃的**废弃指挥所**。

## 结构特征

- 生成于森林、平原、针叶林、热带草原、沙漠和山地
- 使用木材、羊毛和石料建造
- 内置**沙盘**（指挥官工作站点）
- 带有军用物资的战利品箱

## 变体

| 变体 | NBT | 群系条件 |
|------|-----|----------|
| 经典 | `command_post/classic.nbt` | 默认 |
| 沙色 | `command_post/sand.nbt` | 恶地/沙漠群系 |
| 废弃经典 | `command_post/ruined_classic.nbt` | 默认（废弃） |
| 废弃沙色 | `command_post/ruined_sand.nbt` | 恶地/沙漠（废弃） |

结构使用`terrain_adaptation: beard_thin`填充底部空隙，防止在不平坦地形上悬空。

## 生成参数

- **间距：** 48区块
- **间隔：** 10区块
- **盐值：** 741852963
- **群系：** `#millager:has_structure/command_post`（排除苍白之园和冰刺之地）

生成时过滤水域（检查`WORLD_SURFACE_WG > OCEAN_FLOOR_WG`）。Y坐标随地形自适应，入土1–3格。
