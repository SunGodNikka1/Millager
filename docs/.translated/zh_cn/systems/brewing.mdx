# 酿造系统

Millager添加了一套**两阶段炼药锅酿造系统**，用于生产[烈酒](/content/items/liquor)和[灵药](/content/items/elixir)。此系统与原版酿造台完全独立。

## 流程总览

```
农作物 → [装有烈酒的炼药锅] → 烈酒 → [酿造中的炼药锅] → 灵药
```

### 第一阶段：装有烈酒的炼药锅

1. 在世界中放置一个[装有烈酒的炼药锅](/content/blocks/liquor_cauldron)
2. 用**水**填充（用水桶右键，或等待雨天）
3. 加入**农作物**——以下任意：小麦、马铃薯、甜菜根、小麦种子
4. 炼药锅开始酿造
5. 用**玻璃瓶**取出烈酒

### 第二阶段：酿造中的炼药锅

1. 在世界中放置一个[酿造中的炼药锅](/content/blocks/brewing_cauldron)
2. 用**烈酒**填充（手持烈酒瓶右键）
3. 加入**稀有原料**开始酿造灵药
4. 方块实体跟踪酿造进度
5. 用玻璃瓶取出灵药

## 原料

### 烈酒炼药锅输入

| 原料 | 产出 |
|------|------|
| 小麦 | 烈酒 |
| 马铃薯 | 烈酒 |
| 甜菜根 | 烈酒 |
| 小麦种子 | 烈酒 |

必须使用全部四种原料才能解锁**"本地酿酒厂"**进度。

### 酿造炼药锅输入

| 原料 | 产出 |
|------|------|
| 稀有原料 | 灵药 |

## 关联物品

- [烈酒](/content/items/liquor)——中间产物
- [灵药](/content/items/elixir)——最终产品

## 关联进度

- **"小酌怡情"**——酿造出第一瓶烈酒
- **"本地酿酒厂"**——用全部4种原料酿造
- **"灵花妙药"**——饮用灵药
