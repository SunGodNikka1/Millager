# Illager Head

<PrefabObtaining />

A decorative skull block with floor and wall placement variants. Plays the **Illager** (Pillager) instrument when powered by a Note Block.

## Properties

| Property | Value |
|----------|-------|
| Hardness | 1.0 |
| Push Reaction | Destroy |
| Note Block | Illager |

## Placement

- **Floor** — place on the ground like any block
- **Wall** — place on a wall surface (shifts to wall variant)

## Instrument

When placed on top of a Note Block, the block plays the **Illager/Pillager** sound (custom instrument).

## Obtaining

- Dropped by a **Charged Creeper** explosion that kills an Illager
- Also available as the [Illager Head item](/content/items/illager_head)
