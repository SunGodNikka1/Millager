# Villager Head

<PrefabObtaining />

A decorative skull block with floor and wall placement variants. Plays the **Villager** instrument when powered by a Note Block.

## Properties

| Property | Value |
|----------|-------|
| Hardness | 1.0 |
| Push Reaction | Destroy |
| Note Block | Villager |

## Placement

- **Floor** — place on the ground like any block
- **Wall** — place on a wall surface (shifts to wall variant)

## Instrument

When placed on top of a Note Block, the block plays the **Villager** sound (custom instrument).

## Obtaining

- Dropped by a **Charged Creeper** explosion that kills a Villager
- Also available as the [Villager Head item](/content/items/villager_head)
