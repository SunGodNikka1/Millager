# Liquor Cauldron

<PrefabObtaining />

A functional cauldron used in the first stage of the Millager brewing system. Fill with water and add crops to produce [Liquor](/content/items/liquor).

## Properties

| Property | Value |
|----------|-------|
| Hardness | 2.0 |
| Tool | Pickaxe |
| Full Block | No (cauldron shape) |

## Functionality

- Fill with water (right-click with water bucket or wait for rain)
- Add **crops** (wheat, potato, beetroot, wheat seeds) to brew Liquor
- Bottle the Liquor using a glass bottle
- See the [Brewing](/systems/brewing) guide for the complete brewing pipeline

## Breaking

Broken with a Pickaxe. Drops itself.
