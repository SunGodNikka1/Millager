# Totem Infuser

<PrefabObtaining />

A workstation for infusing Totems of Undying with protective enchantments. Emits a light level of 12.

## Properties

| Property | Value |
|----------|-------|
| Hardness | 1.5 |
| Tool | Pickaxe |
| Light Level | 12 |
| GUI | Yes |

## Functionality

- Right-click to open the Totem Infuser GUI
- Place a Totem of Undying in the input slot to begin infusion
- The block plays the **Totem Infuse** sound during operation

## Breaking

Broken with a Pickaxe. Drops itself.
