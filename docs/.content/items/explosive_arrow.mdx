# Explosive Arrow

An arrow tipped with an explosive charge. Can be fired from any bow to create a small explosion on impact.

<PrefabObtaining />

## Usage

- Fired from any bow (vanilla or modded)
- Explodes on contact with blocks or entities
- Does **not** destroy blocks (entity-only damage)
- [Archer](/content/entities/archer) Millagers craft and use these in combat
- Also functions as a regular arrow
